Using Cauchy--Schwarz and the polynomial decay $\mathbb P(E_N^{\mathrm c})\le N^{-\varepsilon}$,
\[
    \left|\mathbb E\!\left[\mathcal M_{\ell_N}^{\mathrm b}\mathbf 1_{E_N^{\mathrm c}}\right]\right|
    \le
    \mathbb E\!\left[(\mathcal M_{\ell_N}^{\mathrm b})^2\right]^{1/2}\mathbb P(E_N^{\mathrm c})^{1/2}
    \le
    O(\log^3 N)\cdot N^{-\varepsilon/2}
    =
    o_N(\log N).
\]
