\begin{block}{SLLN at block times $k\ell_N$}
The increments
\[
    \Big(\min\big(\mathcal V^{\mathrm{upper}}_{(k+1)\ell_N}-\mathcal M^{\mathrm{upper}}_{k\ell_N}\big):k\in\N\Big)
\]
form an i.i.d.\ sequence with the same distribution as $\min\mathcal V^{N|0}_{\ell_N}$.
To apply SLLN (for fixed $N$), we check
\[
    \E\!\left[\min\mathcal V^{N|0}_{\ell_N}\right]
    =
    \E\!\left[\mathcal M^{N|0}_{\ell_N}\right]
    <\infty,
\]
and then obtain, using SLLN together with the $\mathrm L^2$ trajectory limit theorem (Theorem 1.1 / \texttt{proposition:3.1}),
\[
    v_N
    =
    \lim_{k\to\infty}\frac{1}{k\ell_N}\mathcal M^{N|a}_{k\ell_N}
    \le
    \frac{1}{\ell_N}\E\!\left[\mathcal M^{N|0}_{\ell_N}\right].
\]
\end{block}
