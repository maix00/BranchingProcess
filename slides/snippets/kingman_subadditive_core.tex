\begin{block}{Existence of the speed (Kingman)}
Define the subadditive array $(X_{m,n})_{0\le m<n}$ so that
\[
    -v_N
    :=
    \lim_{n\to\infty}\frac{1}{n}X_{0,n}
    =
    -\lim_{n\to\infty}\frac{1}{n}\min W_{0,n},
\]
where the limit exists a.s.\ and in $\mathrm L^1(\mathbb P)$ and is constant by Kingman's subadditive ergodic theorem.
By construction, $\mathcal M^N_n$ has the same distribution as $W_{0,n}$ for all $n\ge 0$, hence
\[
    \lim_{n\to\infty}\frac{1}{n}\mathcal M^N_n=v_N.
\]
\end{block}
