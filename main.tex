    论文研究了有限方差 ($\alpha=2$) 情形下, 具有一般分支律的 $N$-分支随机游走 ($N$-BRW) 前沿演化的渐近性质. 该模型描述了从 $\lfloor N^a\rfloor$ ($a\in[0,1]$)个粒子出发, 每一代根据一般分支律 $\Xi$ 进行繁殖, 并仅保留所有子代粒子中位置最靠前的 $N$ 个个体的演化过程. 该课题源于统计物理中的 Brunet-Derrida 速率修正猜想, 具有重要的理论研究价值. 

    论文取得的主要创新性成果如下：
    \begin{itemize}
        \item 实现了 $N$-BRW 轨迹的 $\mathrm L^2$-极限定理的推广与验证. 论文在脊柱分解框架下, 利用 Mogul'skiĭ 小偏差定理建立了水平和倾斜管道的概率估计. 通过引入分支律交叉项的负指数约束与最左侧位移的矩约束, 成功将既有文献中针对特定 Poisson 分支律模型建立的 $L^2$-轨迹极限定理推广至满足一般矩条件的分布情形. 证明了在三次对数时间与一次对数空间的缩放尺度下, 前沿位置收敛于线性轨迹 $-a+\frac{\pi^2}2\sigma^2t$.
        \item 改进了单粒子起始情形 ($a=0$) 的证明策略.  针对 $a=0$ 时由于位移截断可能导致的种群灭绝风险, 论文构造了带有``重启机制''的耦合过程. 利用分支过程的超临界性质构造至多二分叉过程, 在额外的最左侧位移指数矩假设下, 并配合下鞅估计控制位置偏移, 补齐了该$L^2$-极限定理在全参数空间下的逻辑链条. 
        \item 严格确立了一般分支律下的渐近速率标度律.  论文利用所建立的轨迹极限定理和耦合技术, 在论文给出的假设条件下, 严格验证了渐近速率修正项相对于种群规模 $N$ 的 $\log^{-2}N$ 标度律, 并且在上界的证明中利用上述带有``重启机制''的耦合过程的性质, 去除了直接引用上述极限定理所需的关于最左侧位移指数矩的过严假设.
    \end{itemize}
    论文工作表明, 作者掌握了概率论与数理统计专业坚实的基础理论和系统的专门知识, 具备独立从事科学研究工作的能力. 论文结构严谨, 推导详尽, 写作规范, 达到了理学硕士学位论文的要求. 

    论文尚存在以下不足之处：虽然作者的研究表明, 渐近速率定理中关于最左侧位移正部四阶矩的假设（假设 8) 已可减弱至一阶矩 (假设 7), 但论文中关于分支律交叉项的二阶矩假设 (假设 6) 仍有进一步减弱的空间；此外, 目前的分析框架尚未涵盖厚尾或稳定分布情形. 

    答辩人对论文内容叙述清楚, 回答问题准确. 反映了作者具有良好的学术素养. 经无记名投票表决, 答辩委员会一致同意通过该论文答辩, 并建议授予答辩人王逸扬理学硕士学位.
